앨범 전체를 GitHub Pages에 올릴 수 있는 ZIP으로 저장해요. 사진과 편집 화면도 함께 들어 있어요.

  1. ZIP을 내려받고 압축을 풀어요.
  2. GitHub 저장소의 Add file → Upload files에서 기존 파일과 같은 위치에 올려요.
  3. 변경을 저장하면 Pages가 앨범을 갱신해요.

사진이 많으면 한 번에 올리기 어려울 수 있어요. 그때는 GitHub Desktop으로 폴더를 동기화하면 돼요.

GitHub Pages에 게시한 사진은 인터넷에 공개돼요. 이 편집 화면은 공개 사진을 변경할 권한을 제공하지 않으며, 편집한 사람의 브라우저에만 사본을 저장해요.
